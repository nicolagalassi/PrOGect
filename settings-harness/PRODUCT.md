# Product

## Register

product

## Users

OGame players running the PrOGect userscript (an OGLight-based companion tool) directly inside the game in-browser. They open the settings/panels mid-session to configure fleet defaults, limiters, expeditions, spy tables, keyboard shortcuts. Context: dense strategy game UI, dark background, quick in-and-out task, not a place to linger.

## Product Purpose

Configure the tool fast and get back to the game. Success = every option is scannable and adjustable in seconds, the panel feels native to OGame's dark UI, and nothing distracts from the game underneath.

## Brand Personality

Quiet, precise, native. Should read as a first-party OGame tool, not a bolt-on. Three words: dark, compact, trustworthy.

## Anti-references

- The failed iterations in this project: garish orange, overlapping CSS-grid cards, giant playful toggles, cramped/clipped accordions.
- Marketing-style settings pages (big hero, illustrations, whitespace-heavy). This is a dense tool panel, not a landing page.
- Reinvented form controls that don't behave like standard checkboxes/selects.

## Design Principles

1. Disappear into the task — earned familiarity over novelty.
2. Density with rhythm — many options, but scannable rows and clear section grouping.
3. One consistent control vocabulary — the same toggle, input, select, and "open sub-panel" affordance everywhere.
4. Native to OGame's dark graphite theme; violet accent only for actions/selection/state.
5. Everything ports back into the userscript's inline CSS with real OGLight selectors — no framework, no new DOM shapes.

## Accessibility & Inclusion

Body text ≥4.5:1 on the dark surfaces; visible focus rings on every control; existing colorblind-mode toggle respected; keyboard-operable.
